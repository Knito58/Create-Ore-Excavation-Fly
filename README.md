# Create: Ore Excavation Fly

Ore veins and drilling machines powered by rotational force, for **Create Fly** on **Minecraft 26.3 (Fabric)**.

This is a stripped-down port of [Create: Ore Excavation](https://github.com/tom5454/Create-Ore-Excavation) by tom5454 (MIT).
Fluid extraction and the optional integrations are intentionally not ported.

**Status:** work in progress, not playable yet.

The original NeoForge 1.21.1 sources are kept in `reference/` as a porting aid and are not built.
See `Credits.md` and `LICENSE`.
